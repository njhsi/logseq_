# logseq_
gists

added support to encrypt/decrypt a block with password. the password is also encrypted by your own rsa public key, and saved along with the encrypted block.


the encrypted block content is formated as three lines:
TITLE\n
PASSORD_RSA_ENCRYPTED\n
BLOCK_ENCRYPTED
